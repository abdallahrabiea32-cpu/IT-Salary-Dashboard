# IT Salary Dashboard

An interactive data analysis dashboard built with Python and Streamlit to explore IT salary survey data.

## Project Overview

This project provides an interactive way to explore IT salary survey data through visualizations and filters.

## Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## Features

- Interactive data visualizations
- Data exploration and filtering
- Insights into IT salary survey data

## Dataset

The project uses the IT Salary Survey EU 2020 dataset.

## Run Locally

1. Clone the repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`
